보호자께서 앱 버전, 기기 모델, iOS 버전, 문제가 발생한 화면과 재현 순서를 보내 주세요. 아이의 실명, Apple 계정 비밀번호, 카드 정보나 전체 백업 파일은 보내지 마세요. 화면을 첨부할 때는 이름과 민감한 정보를 가려 주세요.

무료 범위와 전체 이용권

iOS에서는 8급·준7급·7급 150자가 무료입니다. 전체 이용권은 준6급부터 4급까지 추가하여 총 1,000자의 학습을 제공합니다. 한 번 구매하는 비소모성 상품이며 자동 갱신이나 정기 결제는 없습니다. 한국 판매 가격은 6,600원이며, 구매 전 App Store의 실제 표시 가격을 확인해 주세요. 같은 설치의 모든 학습 프로필에 적용됩니다. Android는 현재 전체 범위를 무료로 제공합니다.

구매를 복원하려면

  1. 처음 구매한 Apple 계정으로 App Store에 로그인합니다.
  2. 앱의 첫 프로필 화면 또는 각 탭 오른쪽 위 프로필 메뉴에서 보호자 메뉴를 엽니다.
  3. 화면에 표시되는 계산 문제를 풀고 구매 복원을 누릅니다.
  4. 확인이 지연되면 네트워크 상태를 확인한 후 구매 정보 다시 확인을 누릅니다.

승인 대기 중인 구입은 승인 후 반영됩니다. 복원해도 열리지 않으면 다시 구매하기 전에 지원 이메일로 문의해 주세요. 환불은 Apple 환불 요청에서 진행할 수 있으며 Apple의 처리 기준을 따릅니다.

구매 복원은 학습 기록을 복구하지 않습니다. Apple 가족 공유와 Android 간 구매 공유는 제공 범위에 포함되지 않습니다.

새 기기로 학습 기록 옮기기

  1. 기존 앱의 프로필 메뉴 → 백업·복원을 열고 보호자 확인을 완료합니다.
  2. 백업 파일 저장을 눌러 iCloud Drive 등 앱 외부 위치에 JSON 파일을 저장합니다.
  3. 새 앱의 첫 화면 → 백업·복원 → 보호자 확인 → 백업 파일 열기에서 파일을 선택합니다.
  4. 미리보기를 확인하고 복원합니다. 기존 기록을 덮어쓰지 않고 새 프로필로 추가합니다.

백업은 수동입니다. 앱 삭제 전 반드시 앱 외부에 저장해 주세요. 이미 저장한 백업 파일은 프로필을 삭제해도 남아 있으므로 필요 없으면 파일 앱에서 직접 삭제해 주세요.

프로필과 기록 삭제

공부 중이라면 프로필 메뉴에서 다른 사람으로 바꾸기를 눌러 프로필 선택 화면으로 이동합니다. 해당 프로필의 메뉴 → 삭제 → 확인 → 보호자 확인을 거치면 연결된 학습 기록이 함께 삭제됩니다. 이 작업은 되돌릴 수 없으며 구매 취소나 환불은 아닙니다.

공부와 모의시험 안내

  • 쓰기는 본보기와 비교해 직접 확인하는 연습입니다.
  • 모의시험은 실제 시험과 출제 유형이 다른 객관식 연습입니다.
  • 모의시험 제한 시간은 앱을 닫아도 계속 흐릅니다.
  • 학습 기록은 기기에 저장되며 운영자가 원격으로 복구할 수 없습니다.
