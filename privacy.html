한자 급수 공부 개인정보처리방침

한자 급수 공부 운영자는 앱의 학습 정보가 어떻게 처리되는지 아래와 같이 안내합니다.

기기에 저장하는 정보

앱은 프로필 이름 또는 별명, 목표 급수, 학습 날짜와 풀이 결과, 읽기·쓰기 진도, 오답노트, 필기 획, 모의시험 결과와 중단한 공부 정보를 기기에 저장합니다. 이 정보는 학습 이어하기와 복습·기록 표시를 위해 사용됩니다. 실명을 입력할 필요가 없으며 별명을 사용할 수 있습니다.

앱은 별도의 회원가입 서버를 운영하지 않으며, 위 학습 정보를 운영자의 서버로 전송하지 않습니다. 광고·추적·사용자 분석 SDK를 사용하지 않습니다. 카메라, 마이크, 연락처와 위치 정보를 요구하지 않습니다.

무료 제공

8급부터 4급까지 한자 1,000자와 모든 학습 기능을 무료로 제공합니다. 앱에는 인앱 결제나 구독이 없으며 구매 상태를 조회하지 않습니다.

백업과 외부 저장소

보호자는 확인 절차를 거쳐 학습 정보를 JSON 파일로 저장하거나 해당 파일을 열어 복원할 수 있습니다. 백업에는 모든 프로필의 이름·학습 기록·필기가 포함될 수 있으며, 앱 자체에서 파일을 암호화하지 않습니다. 파일은 보호자가 선택한 기기 폴더 또는 iCloud Drive 등 저장 서비스에 보관됩니다. 해당 서비스의 저장·동기화·보관 방식에는 그 서비스의 약관과 개인정보처리방침이 적용됩니다. 앱은 백업을 운영자의 서버로 보내지 않습니다. 기기의 운영체제 백업 포함 여부는 기기와 계정의 백업 설정에 따릅니다.

보관과 삭제

학습 정보는 해당 프로필을 삭제하거나 앱의 저장 데이터를 삭제할 때까지 기기에 보관됩니다. 프로필 선택 화면에서 해당 프로필의 메뉴 → 삭제 → 보호자 확인을 거치면 그 프로필과 연결된 학습 기록을 삭제할 수 있습니다. 운영자는 기기 안의 학습 기록을 원격으로 열람하거나 복구할 수 없습니다.

앱에서 프로필을 삭제해도 이미 외부에 저장한 백업 파일이나 운영체제의 백업은 자동 삭제되지 않습니다. 이 파일들은 보호자가 해당 저장소에서 별도로 삭제해야 합니다.

어린이와 보호자

앱은 어린이의 한자 학습과 보호자의 학습 관리를 위한 기능을 제공합니다. 별명 사용을 권장하며, 백업·복원과 프로필 삭제에는 보호자 확인 절차를 둡니다. 이 확인 절차는 앱 메뉴 접근을 제한하는 기능이며, 법적 연령 인증이나 정보 수집에 대한 동의 절차를 대신하지 않습니다.
